# Filo Duty - Duty Interaction Points Creator Script

## Overview
A comprehensive script framework for FiveM's duty system management, featuring client-server interaction points, marker systems, and player control interfaces.

## Key Features
- Configurable markers with optional effects
- Multi-duty support with job integration
- Client-server synchronization
- Duty toggle UI controls
- Modular dependency system

## Dependencies
- [ox_lib](https://github.com/overextended/ox_lib)
- [community_bridge](https://github.com/TheOrderFivem/community_bridge)
- [ox_target](https://github.com/overextended/ox_target)

## Usage
Use `/dutycreator` command to manage duties

## Configuration Options
- Duty color scheme: Config.Marker.color
- Command prefix: Config.Command
- Debug mode: Config.Debug
- Marker animation: Config.Marker.bobUpAndDown
